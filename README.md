# 织锦工作室 · 生产排程与色线库存联动台

直接用浏览器打开 `index.html` 即可使用，无需服务器。全部数据保存在浏览器 localStorage，刷新后方案、工序、库存与流水均保留。

## 功能流程

1. **色线库存**：录入色线（名称/颜色/材质/库存），支持补充入库、盘点调整、删除（有占用或被方案引用时拦截）。实时显示 库存 / 已占用 / 可用。
2. **纹样方案**：录入经纬规格（经线根数、纬密、门幅、织长、批量）与经纬两向的色线用量，一键拆分为「整经 → 穿综 → 织造 → 后整理」四道工序。
3. **机台排程**：选择待排工序、机台、日期。排程前实时校验并预览色线需求：
   - 库存不足时禁止排程；
   - 同一机台同一天不能重复安排；
   - 排程成功即占用对应色线。
4. **完工登记**：登记每色实际耗线，库存按实耗扣减、计划占用同步释放；已完工/已取消的排程重复完工会被拦截。
5. **取消排程**：已占用的色线自动退回库存，工序回到待排程。
6. **库存流水**：入库、排程占用、取消退回、完工扣减、盘点调整全程留痕。

页面顶部「载入演示数据」可一键生成示例色线与方案，便于体验完整流程；「清空数据」可重置。另附 `pattern.html` 纹样排版台（网格绘制、用色统计、撤销重做、导出 JSON）。

## 回归测试

```bash
node test.js    # 或 npm test
```

从 `index.html` 提取数据层逻辑，在 localStorage 桩上驱动真实状态机，共 61 项断言，覆盖：方案拆分、库存不足、机台日期三态冲突（进行中/已取消/已完工）、取消退回、完工结算、重复完工拦截、刷新恢复。每个分组独立初始状态，失败时标注所属流程并以退出码 1 结束。
